# Шаблон письма для настройки WebView

Использовать как основу запроса с данными для настройки WebView. Для каждого окружения отправлять отдельный набор данных. При добавлении сервиса в тестовую среду письмо с origin и capabilities отправлять вместе с Jira-заявкой; порядок отправки не важен.

Перед отправкой PM получает origin и список capabilities у frontend-команды. Нужность и значение callback/result URL зависят от проекта; PM уточняет их у команды проекта. Если callback/result URL не используются, явно написать «не используются». Если их нужно добавить позднее, запросить настройку у ДЦРМС через Telegram.

```text
Тема: Настройка WebView — [Название проекта] — [Окружение]

Доброго дня, коллеги!

Просим оказать содействие в настройке и отображении сервиса [Название проекта]
в [тестовой / production] среде мобильного приложения МБанк.

Домен сервиса: [домен]

[Краткое описание проекта]

Направляем данные для настройки WebView:

Окружение: [dev / test / prod]
Origin страницы: [https://example.kg]
Список capabilities: [список от frontend-команды]
Callback/result URL: [URL или «не используются»]

Для тестовой среды также просим добавить следующих сотрудников компании MDigital:
[ФИО], тел.: +996XXXXXXXXX, [должность]
[ФИО], тел.: +996XXXXXXXXX, [должность]

Заранее благодарю за помощь и поддержку.

С уважением,
[ФИО]
[Должность]
ОсОО «Мдижитал»

Telegram: [Telegram ID]
```

Для production-размещения продублировать остальные сведения о сервисе, домене и Bridge и указать выбранную владельцем категорию сервиса. Если в production повторяется список сотрудников, передать ФИО и должности без номеров телефонов. Например, категория сервиса может быть «Страхование». Для тестовой среды в списке сотрудников достаточно ФИО, телефона и должности.

Список capabilities PM получает у frontend, не подбирает самостоятельно. Таблица соответствия событий и разрешений есть в [технической памятке PM](../technical-reference.md).

Этот шаблон описывает письмо для настройки WebView. Jira-заявку на добавление сервиса в тестовую среду и письмо с origin/capabilities отправить вместе: в Jira указать домен, выбрать отдел тестирования и технической поддержки ДЦРМС и отметить ответственных, как описано в [PM-процессе](../README.md#3-добавить-сервис-в-тестовую-среду).
